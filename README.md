# YouTube Speed Buttons

Chrome 擴充功能：在 YouTube 影片播放器右下方提供快速調整播放速度的按鈕。

## 安裝方式

1. 在 Chrome 開啟 `chrome://extensions`。
2. 開啟右上角的「開發人員模式」。
3. 點選「載入未封裝項目」。
4. 選擇下載或複製後的專案資料夾（包含 `manifest.json` 的資料夾）。
5. 重新整理已開啟的 YouTube 分頁。

## 使用方式

- 將滑鼠移到影片播放器上，右下方會出現 `0.5×` 至 `2×` 的速度按鈕。
- `−` 與 `+` 分別以 `0.25×` 遞減、遞增，支援範圍為 `0.25×` 到 `4×`。
- 鍵盤 `[` / `]` 也能以 `0.25×` 調整速度。

擴充功能只在 `youtube.com` 頁面執行，且不會傳送或儲存資料。
